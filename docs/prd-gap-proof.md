> v0.4 · 2026-10-21（v0.4：吸收 dogfood 查新 #01——**先扫用户自己的参考文献**、加预印本源。v0.3：开放问题 O1–O5 全部定案——按维度判、全新事件模型、驳回只在危险方向加摩擦、循环不等人、切刀顺序；召回金标准集定稿。v0.2：吸收两份冷读——检索失败≠零命中、术语表、签名语义、价值场景收窄、段落/检索/结论改用新事件）· 决策来源：`docs/grill-reading-first.md`（D1–D14，Arnold 逐条定）· 依据：#3 走查（「基本不可用」，8 条发现）、`docs/competitor-scan-gap-search.md`（竞品扫描）· 本文给 Arnold（决策）和 spec 作者读；只写做什么、给谁、为什么，怎么做交给 spec。面向用户的文案另写。

## 一句话
**帮正在写开题、基金申请的硕博回答「有没有人做过 X」，并交出一份经得起导师追问的证明：在哪些库、用什么检索式、哪个出版年限范围内搜过，读了哪些原文段落，为什么它们不算覆盖。**

价值在**自己和导师**这里，以及**花钱做正式查新之前的自查**。评审不看检索日志，这份证明不是给评审的（冷读·博士生）。

## 问题
- **谁**：要论证一个研究空白的硕博（开题、基金申请、投稿 related work）。导师会问：「你怎么知道没人做过？」
- **gap 的真实形状**：医学类的 gap 很少是「完全没人做过」，多半是「没在某个人群 / 模态 / 方法 / 结局下做过」⇒ 结果大多会是「部分覆盖」，产品必须讲清楚**差在哪一维**（见开放问题 O1）。
- **今天怎么做**：Google Scholar 手搜、问 Claude、托人工科技查新。
- **为什么不够**：

| 现有做法 | 缺什么 |
|---|---|
| 直接问 Claude / 通用 Deep Research | 能说「没人做过」，证明不了；会漏，会编引用，会顺着你说 |
| Edison Precedent（专问「有没有人做过」）| 只给一个答案和一个是/否：无检索边界、无逐篇人判、无导出 |
| Elicit 系统综述 | 审计骨架最全，但为「纳入证据」设计；你推翻 AI 时它不反驳；完整审计锁在企业版 |
| Undermind | 能说出为什么停，但检索式不可见，无边界报告 |
| 人工科技查新 | 格式正对（检索工具 + 时间范围 + 检索式 + 对比文献 + 结论），但付费、人工、慢 |

**#3 走查教训（不再重犯）**：旧旅程替用户想假设、挑检索词、读摘要、找空白，把「5 篇摘要没提到」签成了已确认 gap。严谨的词汇包着没人读过的 LLM 总结，比直接问 Claude 还繁琐。

## 我们做什么
**核心循环（覆盖模式）**

1. 你写一句 X（一个方法、问题或组合），设预算（默认 30 篇候选 / 10 次检索）。AI 把 X 拆成 2–5 个**维度**（临床问题用 PICO：人群 / 干预 / 对照 / 结局；计算类用 方法 / 数据 / 对象 / 任务），你来改。
2. **先扫你自己的参考文献**：导入你的 .bib / RIS（或 Zotero），逐篇核对是否已覆盖 X。反例常常就躺在你已经引用、却没读透的文献里。
3. Agent 自动迭代：多源检索（本地语料、arXiv、OpenAlex、**PubMed（带 MeSH）、EuropePMC（含 medRxiv / bioRxiv 预印本）、PsyArXiv / OSF 预印本**），每次检索都记录检索式、源、出版年限、命中数、检索日期。**检索失败记为「失败」，不是「0 命中」**。PubMed 检索式要能复制到 PubMed 重跑，且命中数对得上。
4. 每篇候选取全文：开放获取自动抓取，**Zotero 导入**，手动上传 PDF。**一开始就标出哪些论文拿不到全文**。摘出与 X 最相关的 1–3 段原文，带位置（页码或章节），可点开看上下文。
5. AI 对每篇论文**逐个维度**给出候选判断（覆盖 / 不覆盖，附段落），整体「覆盖 / 部分覆盖 / 不覆盖」由维度自动推出，呈现为**论文 × 维度矩阵**。你读段落后确认（可整行 / 整列批量）或改判。**只在危险方向加摩擦**：你把 AI 的「覆盖」改成「不覆盖」（驳回）时写一行理由，AI 有原文证据才反驳、最多一轮，你坚持即算，全程留痕；改成「覆盖」点一下即可。
6. 反证搜索：换说法、**引用追溯**（最近几篇的参考文献与被引）、邻近领域（X 拆成方法 + 对象分开搜）。你的驳回会触发再搜，并留痕。
7. 停：连续两轮没有新的相关命中，或碰到预算。停下时必须说明是因为哪一条停的。
8. 出**结论**（一个对象，两种结果）：「有人做过：在这几篇的这几段」，或者「在这些范围内没找到」（＝gap，表述为**没有一篇同时覆盖的维度组合**，例如「A、B、C 各有人做过，但没有一篇同时覆盖 A × C」）。两种都要你**签名**，签名＝你确认这份结论及其边界。签名前，离 X 最近的 3 篇（判为部分覆盖、与 X 差得最少的）须核过全文；拿不到全文的，要逐篇写理由并标「摘要级」。签名后不再改；有新发现就出新版本。
9. 导出**查新报告式的缺席证明**（中文 Markdown；Word 以后）：检索工具与出版年限、检索式（含失败的源）、对比文献及段落、逐篇判断、带边界的结论。区域结论只覆盖所检的国际库，不含中文库。

**第二个模式（紧跟覆盖模式上线）**：支撑模式，「我认为 Y」。每段判断为支持 / 反驳 / 没提到，**必须两边都搜**：每找到一条支持，都主动去找反驳，两边并排呈现。

## 原则（铁律）
- **结论永远带边界**：触预算而停时，只能写「在这些范围内没找到」，不写「没人做过」。
- **失败不等于没有**：某个源检索失败（超时、限流、报错），必须记为失败并写进边界；不能把失败的源算作「已检未见」。（冷读·工程师：现有抓取器出错都静默返回空列表，**必须先修**）
- **只有摘要不能证明缺席**：只拿到摘要的论文最多判「摘要未提及」。确实拿不到全文时，你要写理由、自担风险，签名带「摘要级」标记。
- **AI 自动化取证，人做判断与签名**：检索、生成检索词、摘段落、候选判断、反证搜索由 AI 做；写 X、确认或改判、签名只能你做。
- **不生成假设，不写研究正文**：#22 的出发点假设删除；gap 文本就是 X 加覆盖证据链。
- **跨查询只复用「读」，不复用「判」**：读过的论文和段落（带角度标签）留给下一个 X 复用；判断每个 X 都重判，旧理由只作参考显示。

## 本期不做
- 研究正文协作：不生成能直接粘进开题的论述。
- 从一堆 gap 推演、在论文之间串联、「还能读什么」（第二阶段）。
- gap 签名后有新论文出现时主动提醒（第二阶段）。
- 入门帮读：术语解释、双语释义、一起读。
- 导师侧功能、CNKI / 万方、收费。
- 替代正式科技查新：导出物明确标注「自助查新，不具正式查新效力」。

## 形态与约束（给 spec 的输入）
- **Web app，自带 agent**：在现有 Python 后端写结构化循环（搜 → 摘段落 → 判 → 反证，LLM 决定下一次检索）；不换 Go；Claude Agent SDK 留作以后需要开放式 agent 时的备选。
- **每一步写成事件**：后台跑，前端看进度，可恢复；审计链就是事件流。新增事件：检索记录、段落、覆盖判断（照证据候选的生命周期新写，不借用「支持 / 反驳」语义）、结论。X 是否复用 workspace 待 spec 定（workspace 现有生命周期是旧旅程语义）。**冷读更正 v0.1**：现有 anchor 只锚用户笔记；material 作者写死 "user" 且绑定 workspace；gap 事件只装一条检索式 ⇒ 都装不下，不硬套（见开放问题 O2）。
- **旧旅程**（claim、审查轮、证据台、方向、结晶）留在内核，退出主界面；六阶段页换成单一查询页。
- 解析器：PyMuPDF / GROBID / Docling / DeepSeek 视觉读页面，**由 V3 实测选一个，直接写死**，不做可插拔。硬要求是段落位置稳定，并能拿到章节和参考文献。
- 第一阶段 Arnold 自用、自带 key；LLM 调用按查询计数。

## 成功标准
1. **召回**：3 个**已知有人做过**的 X（**至少 1 个是精神影像 / 医学领域**），Cui 都能找到那篇论文，并摘出对应段落。（自动化，进 canary；需要金标准集，见待验证）
2. **对照 Claude**：在同一组金标准 X 上，Cui 能抓到 Claude 漏掉或编造的覆盖。（有金标准才能自动化，先半人工）
3. **真实使用**：Arnold 的 3 个真实 X，至少一次找到他原先不知道的论文，或者产出一份他愿意放进开题的缺席证明。（人判）

## 术语
| 词 | 意思 |
|---|---|
| X / 查询 | 用户写的一句「有没有人做过 X」；一个 X 对应一次查询页。LLM 用量按 X 计 |
| 检索 | 对某个源跑一次检索式；预算里的「10 次」按检索计 |
| 轮 | agent 规划一次「下一步搜什么」并执行完这一批检索 |
| 覆盖判断 | 每篇论文相对 X：覆盖 / 部分覆盖 / 不覆盖；只看了摘要时，「不覆盖」带「摘要级」限定 |
| 驳回 | 你把 AI 判的「覆盖」或「部分覆盖」改成「不覆盖」 |
| 结论 | 一个对象：「有人做过（列段落）」或「在这些范围内没找到（gap）」，带边界，由你签名 |
| 边界 | 检了哪些源（含失败的）、检索式、出版年限、检索日期、为什么停 |
| 摘要级 | 判断只依据摘要；不能单独支撑「没找到」 |

## 第一阶段切刀（D19）
1 **地基**：修「检索失败≠0 命中」· 查询（X + 维度）· **导入 .bib / RIS 并先扫用户自己的参考文献** · 本地语料 / arXiv / OpenAlex / PubMed（MeSH）检索记录 · 库级论文 · 本地全文规则切段 · 维度判断（AI 候选 + 人确认 / 驳回）· 结论与签名 · 中文 Markdown 导出 · 矩阵查询页 · 简版后台任务 + 轮询 · **召回 canary 接入**
→ 2 **全文**（V3 选解析器 · OA 抓取解析 · 无全文先标 · 手传）→ 3 **agent 化**（迭代 · 停止 · 预算 · 分批 · 断点续跑）→ 4 **反证**（换说法 · 邻近领域 · 引用追溯 · EuropePMC · PsyArXiv / OSF 预印本）→ 5 **AI 反驳** → 6 **Zotero**（先 V4）→ 7 **跨查询复用** → 8 **支撑模式**

## dogfood 证据：查新 #01（2026-10-21）
用本 PRD 的协议手工跑了一次真实查新（作者本人一篇在投论文的新颖性声明；报告不公开）。30 次检索（4 次失败，均记为失败），按维度判断，因预算用尽而停 ⇒ 结论如实写为「证据偏弱」。结论：原声明不加限定不成立，只在一个维度上站得住。对产品的三条证据：
1. **最强的两条反例都不是关键词检索出来的**：一条躺在用户自己已引用的文献里（引用时被误述），一条在预印本服务器上（标题用词与 X 不同）⇒ 本版加「先扫用户参考文献」和预印本源。
2. **关键对比藏在全文的结果表 / 消融里**，摘要看不出 ⇒ 印证「只有摘要不能证明缺席」。
3. **边界原则起作用**：预算停 ⇒ 不写「没人做过」，写「在这些范围内没找到，证据偏弱」；未覆盖的库（ACM DL、Scopus、PsycINFO）列进边界。
